## Architecture & Zero-Storage Philosophy

Rather than storing dozens of heavy agent instructions and prompts on your local machine, this repository acts as a cloud-native agent registry. Antigravity dynamically fetches and assumes the persona of any specialist agent in memory on demand, executes the task with domain perfection, and leaves zero local storage footprint.
